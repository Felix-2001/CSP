Coursework repository for the Client-Side Programming course.

## My Background
I already have experience with HTML and CSS and a background in SEO, so in this project I want to combine well-structured, search-friendly markup with a dynamic, polished design, and add JavaScript to make the booking flow interactive.

## About
A website for a small sauna rental by Kuivasjärvi lake in Seinäjoki. Visitors can
see the three saunas (capacity, price, weekend rates), check which evenings are
free in the next two weeks, and send a booking request.

## Goals
- Accessible design: availability is shown with words and symbols, not just colour
  (colour-blind friendly).
- SEO-friendly structure: one h1, h2 per section, h3 per sauna, descriptive alt text, meta tags.
- Responsive layout for mobile and desktop.
- JavaScript for form validation and sending the request by email through an
email service.

## Tech
HTML, CSS, vanilla JavaScript, email service (EmailJS or Formspree, to be decided).
